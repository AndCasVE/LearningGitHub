> **eLearning roadmap · September 2026**
>
> A structured learning guide for **Course GH-900T00-A: GitHub Foundations**,
> based exclusively on the current Microsoft Learn study guide and learning
> paths.

## Course At A Glance

| | Details |
| --- | --- |
| **Audience** | GitHub beginners, developers, administrators, and anyone who wants a stronger foundation in GitHub |
| **Level** | Beginner to intermediate |
| **Format** | Self-directed eLearning with hands-on exercises |
| **Estimated duration** | 48 hours / 2 days of instructor-led equivalent study |
| **Learning paths** | 2 paths · 16 modules total |
| **Prerequisite** | A GitHub account |

## What You Will Learn

By the end of this eLearning experience, you will be able to:

- Explain the purpose of version control and the relationship between Git and GitHub.
- Use repositories, commits, branches, merging, and GitHub Flow to manage work.
- Navigate GitHub accounts, organizations, products, and core repository files.
- Collaborate through issues, pull requests, discussions, notifications, and Markdown.
- Describe how GitHub Actions, Copilot, Codespaces, and `github.dev` support modern development.
- Plan and track work with GitHub Projects, labels, milestones, fields, and workflows.
- Apply foundational privacy, security, authentication, authorization, and administration practices.
- Recognize ways to participate in open source and InnerSource communities.

## Learning Journey

### Phase 1 · Build the Foundation

**Microsoft Learn path:** [GitHub Foundations Part 1 of 2](https://learn.microsoft.com/en-us/training/paths/github-foundations/)

| # | Module | Focus |
| ---: | --- | --- |
| 1 | [Introduction to Git](https://learn.microsoft.com/en-us/training/modules/intro-to-git/) | Source control fundamentals and the Git version control system |
| 2 | [Introduction to GitHub](https://learn.microsoft.com/en-us/training/modules/introduction-to-github/) | Issues, notifications, branches, commits, and pull requests |
| 3 | [Introduction to GitHub's products](https://learn.microsoft.com/en-us/training/modules/github-introduction-products/) | Account types, plans, features, billing, GitHub Desktop, and GitHub Mobile |
| 4 | [Configure code scanning on GitHub](https://learn.microsoft.com/en-us/training/modules/configure-code-scanning/) | Code scanning with CodeQL, third-party tools, and GitHub Actions |
| 5 | [Introduction to GitHub Copilot](https://learn.microsoft.com/en-us/training/modules/introduction-to-github-copilot/) | AI-assisted code generation, understanding, refactoring, and debugging |
| 6 | [Code with GitHub Codespaces](https://learn.microsoft.com/en-us/training/modules/code-with-github-codespaces/) | Cloud-hosted development environments and dev containers |
| 7 | [Manage your work with GitHub Projects](https://learn.microsoft.com/en-us/training/modules/manage-work-github-projects/) | Issues, tasks, relationships, custom fields, and project conversations |
| 8 | [Communicate effectively on GitHub using Markdown](https://learn.microsoft.com/en-us/training/modules/communicate-using-markdown/) | Clear, concise communication in GitHub content |

**Phase outcome:** You can explain GitHub’s core concepts, navigate its products,
and use its principal collaboration and development tools.

### Phase 2 · Collaborate, Secure, and Contribute

**Microsoft Learn path:** [GitHub Foundations Part 2 of 2](https://learn.microsoft.com/en-us/training/paths/github-foundations-2/)

| # | Module | Focus |
| ---: | --- | --- |
| 9 | [Contribute to an open-source project on GitHub](https://learn.microsoft.com/en-us/training/modules/contribute-open-source/) | Find projects and tasks, create pull requests, and work with maintainers |
| 10 | [Manage an InnerSource program by using GitHub](https://learn.microsoft.com/en-us/training/modules/manage-innersource-program-github/) | Discoverability, guidance, and maintenance for InnerSource |
| 11 | [Maintain a secure repository by using GitHub best practices](https://learn.microsoft.com/en-us/training/modules/maintain-secure-repository-github/) | Secure repository design, hosting, and maintenance practices |
| 12 | [Introduction to GitHub administration](https://learn.microsoft.com/en-us/training/modules/github-introduction-administration/) | Security and control measures for organizations and enterprises |
| 13 | [Authenticate and authorize user identities on GitHub](https://learn.microsoft.com/en-us/training/modules/authenticate-authorize-user-identities-github/) | Authentication and authorization options for GitHub organizations and Enterprise |
| 14 | [Manage repository changes by using pull requests on GitHub](https://learn.microsoft.com/en-us/training/modules/manage-changes-pull-requests-github/) | Manage source changes through pull requests |
| 15 | [Search and organize repository history by using GitHub](https://learn.microsoft.com/en-us/training/modules/search-organize-repository-history-github/) | Repository history with filters, blame, and cross-linking |

repositories, work with project history, and participate in open-source or
InnerSource development.

## Suggested Study Rhythm

1. Complete each module in order and record the concepts you can explain without notes.
2. Revisit the module exercises after each phase and connect them to the objective domains above.
3. Use the official study guide to identify gaps and review the linked module before attempting an assessment.
